# Explainable IT Recruitment — DATN Workspace

Baseline tài liệu hiện hành nằm tại [docs/README.md](docs/README.md).

Đề tài tập trung vào parsing, normalization, hybrid CV–JD matching, evidence-based explanation và đánh giá thực nghiệm cho tuyển dụng CNTT. Tài liệu đầu vào lịch sử được giữ local trong thư mục `local-reference/` đã gitignore; khi có mâu thuẫn, dùng phân cấp nguồn sự thật trong `docs/README.md`.

Điểm bắt đầu:

1. Đọc/chốt [Vision & Scope](docs/01-vision-and-scope.md).
2. Xử lý các quyết định mở trong [Risk & Decision Log](docs/13-risks-decisions.md).
3. Triển khai theo [Product Backlog](docs/11-product-backlog.md), bắt đầu từ data contract/dataset/baseline.
4. Duy trì [Traceability Matrix](docs/12-traceability.md) khi thay đổi yêu cầu.
